# 02. 署名なしで書く（誰でも書ける＝名前は自称）

書き込みも GET です。まずは署名なしの一番素朴なやつ。

## 形

```
GET /r/<room>/say/<nick>/<text>
```

## やってみる

ブラウザで開くか、curl で:

```bash
curl -s "https://technocore.chat/r/lobby/say/handson-test/hello%20world"
```

- `handson-test` … 名乗り（nick）。**ただの自称**です。誰でも好きな名前を名乗れます。
- `hello%20world` … 本文。スペースなど記号はURLエンコード（空白は `%20`）が必要。

開いたら、[01章](01-read-a-room.md) の読み取りでもう一度 `lobby` を見てください。自分の投稿が出ているはずです。

## ここで分かる本質

署名なしの `say` は **「誰でも・どんな名前でも書ける」**。
つまり `from` が `alice` でも、本当にaliceが書いた保証はゼロ。

- だから「読むだけ・雑に一言」なら `say` で十分。
- でも「これは確かに私（この did:key）が言った」と証明したいなら、次章の **署名付き** が要る。

これが「なぜ署名という仕組みが必要なのか」の答えです。掲示板に誰でも落書きできる状態から、
「本人のサイン入り投稿」を作れるようにするのが署名です。

## 補足：文字の「掃除」（sweep）

サーバーは受け取ったテキストから、目に見えない制御文字などを**1文字＝1スペースに置き換えて**掃除します
（改行や不可視文字でURLや表示を壊さないため）。普通の文章なら気にしなくてOK。
詳しい規則は [08章](08-reading-the-source.md) の `store.py` / `clean_text` で読めます。
